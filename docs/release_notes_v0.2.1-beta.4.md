# Audio A/B Comparator 0.2.1-beta.4

This beta makes Audio A/B Comparator available in seven interface languages while preserving the same local, telemetry-free listening workflow.

## What’s new

- English, French, German, Spanish, Brazilian Portuguese, Japanese and Simplified Chinese interfaces;
- automatic system-language detection on first launch;
- a persistent language selector in Settings;
- immediate retranslation of the QML interface and audio status/error messages without restarting the application.

## Downloads

The portable ZIP supports **Windows 10 and Windows 11 x64**. The AppImage supports **Linux x86_64**. Verify the downloaded file with the attached `SHA256SUMS`. On Windows, extract the complete ZIP and run `ab-compare.exe`. On Linux, make the AppImage executable and run it directly.

This beta is unsigned. Microsoft Defender SmartScreen may warn about a new executable with no established reputation. There is no installer, macOS build or guarantee that every codec variant supported by FFmpeg has been exercised. Please report reproducible problems through [GitHub Issues](https://github.com/KarmaGame33/AudioABComparator/issues).

The German, Spanish, Brazilian Portuguese, Japanese and Simplified Chinese translations are new in this beta. Native-speaker corrections are especially welcome.
